# Pen.dev brief — GTA VI confirmed music tracker

Live site (structure to redesign, not restyle as official): https://jonhilt.github.io/gta6-confirmed-music/

Pages to design:
1. **List** (`index`) — filters, search, tiers, entry cards/rows with source links
2. **Methodology** — explains the three tiers

## Vibe
Loud, sweaty, sun-bleached **fan site** energy. Vice City / Leonida / Miami nights without looking like Rockstar shipped it.
- Neon magenta / teal / sunset orange on deep asphalt (not Rockstar’s exact palette lockups)
- Chunky display type + readable body
- Slight grit, stickers, “bootleg flyer” confidence
- Clear banner: **fan documentation · not affiliated with Rockstar / Take-Two**

## Hard no (copyright / trademark)
- No Rockstar / GTA / Take-Two logos, wordmarks, or key art
- No box art, screenshot rips, or official UI chrome as decoration
- Do not make it look like an official Rockstar page
- Linking out to official YouTube trailers with citation is fine; do not host their media

## Must show on List
- Tier badges: `official promo` / `Rockstar-named` / `artist-reported`
- Artist(s) + track (if known) + where it appeared (Trailer 1 / 2 / Extended Look / interview / claim)
- Source links (citeable)
- Filter by tier + text search
- Section or badge for `needs primary source` (Travis Scott / Future / Morgan Wallen style rows)

## Must show on Methodology
- The three tiers in plain speech
- What we refuse (rumors, aggregators-as-proof)
- Copyright note (no lyrics/bios; link-out OK)

## Deliverable in Pen
Two full desktop frames (1440-wide ok) + optional mobile (390-wide) for List.
Name frames clearly. Use original components only.
